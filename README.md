# Asansör Dijital İkiz — sürümler

Bu repo yalnız **Windows exe sürümlerini** dağıtır; kaynak kod burada değildir.

İndirme: sağdaki **Releases** → son sürüm → `AsansorIkiz-win64.zip`.
Zip'i bir klasöre açın; `AsansorIkiz.exe` her açılışta buradaki son sürümü denetler ve gerekirse kendini günceller.

| Dosya | Ne yapar |
|---|---|
| `AsansorIkiz.exe` | Arayüz (Test Paneli, kuyu, tezgah, güvenlik kartı, ACE8000, CAN izi, servis aracı, USB-CAN köprüsü, kuyu öğretme, senaryolar) |
| `Senaryo.exe` | Kabul senaryolarını pencere açmadan koşturur (`Senaryo.exe --hepsi`) |
| `PinTestIzle.exe` | NUCLEO tezgah pin testi izleme aracı |
